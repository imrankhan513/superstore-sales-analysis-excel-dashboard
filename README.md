# 📊 Superstore Sales Analysis Dashboard (Excel)

## 📌 Overview
This project presents an interactive Excel dashboard built using the Superstore sales dataset.
The dashboard provides a clear view of sales performance, customer segments, shipping modes, and regional trends to support data-driven decision making.

## 🧾 Dataset
- Superstore Sales Dataset
- Time Period: 2014 – 2017
- Data Type: Retail transaction data

## 🛠 Tools & Skills
- Microsoft Excel
- Pivot Tables & Pivot Charts
- Slicers (Region & Year)
- KPI calculations
- Dashboard design & formatting

## 📈 Key KPIs
- Total Sales: ₹58,20,182
- Average Sales: ₹582
- Total Transactions: 9,994
- Total Quantity Sold: 25,123

## 🔍 Insights
- Standard Class is the most used shipping mode
- West region generates the highest sales
- Consumer segment orders the highest quantity
- Office Supplies has the most transactions
- Sales quantity peaks during Sep–Nov

## 🎛 Interactivity
- Region filter: Central, East, South, West
- Year filter: 2014 – 2017
